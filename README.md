本系统是一款专为大学理工科（如常微分方程、高等数学等）设计的 **人机协同 AI 教务批改 SaaS 平台**。通过 Multi-Agent 架构与底层符号计算引擎的深度结合，彻底解决传统大语言模型（LLM）在复杂数学推导中频发的“幻觉”与“趋中评分”问题。

---

## ✨ 核心黑科技 (Core Features)

- **🤖 多脑协作流水线 (Multi-Agent System)**
  内置四大智能体：`Extractor`（作业解析）、`ProblemAnalyzer`（标准生成）、`Grader`（评分诊断）、`Analyst`（学情聚合），各司其职，将不可控的 AI 黑盒转化为稳定的教务生产力。
- **🛡️ 符号引擎防幻觉 (Anti-Hallucination)**
  在 AI 对复杂微积分步骤存疑时，系统会强制外挂 **SymPy 符号计算引擎** 进行绝对的数学等价性校验，极大提升理科阅卷的严谨性。
- **👁️ 沉浸式高清阅卷 (High-Res Rendering)**
  底层引入 `PyMuPDF` 将 PDF 实时切片渲染为高清图片流，完美绕过 Chrome 等现代浏览器的 iframe 安全屏蔽机制，支持移动端丝滑跨屏阅卷。
- **📊 动态学情大屏 (Data Dashboard)**
  基于 Pandas 实时聚合成班级分数正态分布图，并精准提取单题高频错因及人群占比，为教研迭代提供数据支撑。
- **📧 自动化防封禁分发 (Automated Distribution)**
  内置高并发邮件发送引擎，支持 CodeCogs API 公式图片化动态渲染（解决邮件客户端屏蔽 LaTeX 脚本问题），实现精美 HTML 成绩单的稳健触达。

## 🛠️ 快速上手指南 (Quick Start)

本系统采用 **BYOK (Bring Your Own Key)** 隐私保护机制，所有数据处理均在内存中流转，不留存任何用户密钥。

### Step 1: 完善系统配置
<img width="927" height="440" alt="model" src="https://github.com/user-attachments/assets/efb188a1-655c-45d5-82be-971448db6a8d" />

1. 在左侧边栏选择你偏好的大模型基座（支持 DeepSeek / 智谱 GLM / 阿里通义千问）。
2. 输入对应的 `API Key`。

### Step 2: 上传与解析
<img width="949" height="402" alt="upload" src="https://github.com/user-attachments/assets/d5bb2e3c-13bd-4a4f-9d86-12438192c6cb" />


1. 准备学生的作业文件（支持包含 LaTeX 源码的 `.tex` 文件及同名 `.pdf` 预览文件）。
2. 点击 **“批量上传”**，系统会自动阅读作业并提取所有题目。

### Step 3: 教师核对 (Human-in-the-loop)
<img width="944" height="392" alt="standard" src="https://github.com/user-attachments/assets/369d258d-778a-409a-8299-57e3f8d63f76" />

1. 系统会自动生成每道题的“标准答案”与“评分量规（Rubric）”。
<img width="940" height="407" alt="fix" src="https://github.com/user-attachments/assets/00335313-eeef-4967-884a-db23779ef4f7" />

2. 教师可在双屏可视化看板中核对公式渲染效果，并对 AI 生成的标准进行人工微调，确保绝对准确。

### Step 4: 批量批改与学情诊断
<img width="944" height="391" alt="confirm" src="https://github.com/user-attachments/assets/e8c9dc8b-92ae-4a88-b9fb-563c8105277e" />

1. 点击 **“开始批量批改”**，系统将自动高并发处理全班作业。
<img width="942" height="443" alt="data" src="https://github.com/user-attachments/assets/c36e982f-154a-4147-bc58-bc2b5758e203" />

2. 批改完成后，自动跳转至 **学情大屏分析**，查看平均分、分数段直方图及高频错题预警。
<img width="947" height="437" alt="teacher" src="https://github.com/user-attachments/assets/5255f576-37b5-4395-a18b-86c1f29b067c" />

3. 教师可展开单个学生的答卷，进行最终的人工微调与反馈修改。

### Step 5: 成绩导出与邮件分发
<img width="937" height="438" alt="ex" src="https://github.com/user-attachments/assets/ae495896-2583-4ad1-b525-41146f33c355" />

- **本地导出**：支持一键下载 Excel 总成绩单，或包含全班独立 HTML 成绩报告的 ZIP 压缩包。
- **邮件直达**：上传学生通讯录（含学号/姓名与邮箱），系统将自动进行模糊匹配，将定制化的成绩报告一对一发送至学生邮箱。（可选）在底部输入发件邮箱及 SMTP 授权码，用于最终的成绩分发。
