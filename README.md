项目名称：基于 Multi-Agent 架构的理科作业智能批改与学情分析系统
项目角色：独立开发者 / 核心架构师
技术栈：Python, Streamlit, LLM SDK (DeepSeek/Zhipu/Qwen), Pandas, SymPy, Regex, SMTP
项目背景：
传统大语言模型在处理复杂数学推导时存在严重的幻觉和趋中评分的问题。本项目旨在构建一个高可用、防幻觉的人机协同作业批改流水线，实现从非结构化作业提取、逻辑校验到数据看板分析的全流程自动化。
核心技术与贡献：
● 构建 Multi-Agent 协同网络：
  ○ 设计并实现了包含 ProblemAnalyzer（解题标准生成）、Extractor（作业解析）、Grader（评分与诊断）、Analyst（数据聚合）在内的多智能体协作框架。
  ○ 采用 State Machine（状态机） 架构重构 Streamlit 前端交互，实现标准生成 、人工微调、批量执行的清晰流转，将不可控的 AI 黑盒转化为可信的教务生产力工具。
● 引入 Tool-use 破解数学幻觉：
  ○ 针对大模型数值计算薄弱的痛点，为 GraderAgent 挂载 SymPy 符号计算引擎工具。在模型对复杂多项式、微积分等式存疑时，强制交由底层计算器进行绝对的等价性校验，极大提升了评分逻辑的严谨性。
● 开发动态学情分析面板：
  ○ 利用 Pandas 对批改结果进行实时聚合与结构化处理，自动生成班级成绩频数分布直方图。
  ○ 开发细粒度特征提取逻辑，下钻分析单题维度的高频错因及人群占比，为教研迭代提供数据支撑。
● 设计高可用多模态分发机制：
  ○ 实现基于 Regex 与 CodeCogs API 的 On-the-fly 公式图片化渲染，解决邮件客户端屏蔽 JS 脚本导致 Markdown/LaTeX 渲染失败的行业痛点。
  ○ 开发基于通讯录双重模糊匹配（学号/姓名）的邮件分发模块，并引入 Connection Pooling（连接池复用）与退避重试（Exponential Backoff）机制，成功绕过 SMTP 服务器的高并发反垃圾风控策略，实现稳健触达。
  ○ 提供基于 zipfile 的全静态 HTML 独立报告导出方案，保障跨端浏览体验。
